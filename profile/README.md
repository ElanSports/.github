# ElanSports AI Library

Shared AI skills and guidance for Elan colleagues. This page explains how to get access; the library and its contents remain private.

## Get started

1. **Use an individual, work-dedicated GitHub account.** [Create a free account](https://github.com/signup) if needed. Register and verify your Elan work email on that account. Do not use a shared team login. **Already testing with another GitHub account?** Contact Matevž before creating a replacement so your existing organization access, forks, and open proposals can be handled safely.
2. **Send your GitHub username to Matevž.** Use your usual internal company channel. Send the username shown in your GitHub profile URL, not just your display name. Never send your password, token, or recovery codes.
3. **Accept the ElanSports invitation.** Matevž grants access; creating an account or receiving an invitation alone does not add you to the organization. Using the same account whose username you provided, open [the invitation page](https://github.com/orgs/ElanSports/invitation) and choose **Join ElanSports**. If offered, **Ask for a GitHub Copilot seat** is optional and not needed for the library.
4. **Connect that account to your AI.** In your AI app's Apps, Plugins, or Connectors settings, connect GitHub and authorize the same personal account. The tested ChatGPT connection is called **ChatGPT Codex Connector**. Other tools need their own supported GitHub connection.
5. **Open the private library.** Once you have accepted the invitation, visit [ElanSports/ai-library](https://github.com/ElanSports/ai-library) and follow its employee guide. If you cannot see the contents, ask Matevž to check access. The link is not accessible before permission is granted.
6. **Verify access in your AI chat.** Ask your AI to read `README.md` from `ElanSports/ai-library` on `main`. Seeing the repository in your browser does not automatically mean the AI connection can read it.

## Important

- Elan email verification is an account-setup requirement, not proof of employment or automatic authorization. Matevž grants and revokes organization access separately.
- You do not need Git knowledge or permission to write directly to the official library.
- Organization app installation is managed by the administrator. If GitHub asks for an organization owner to update access, do not change your role or request broader permissions; return to the personal connection flow or ask Matevž for help.
- Installing a skill in your AI is optional and separate from connecting GitHub. Installation alone does not grant library access.
- Use only company-approved AI accounts and material. Access requests are reviewed; this public page does not grant access to anyone.

After access is granted, the private library explains how to use the creator, submit your own skills for review, and propose updates.
